● Pour exécuter le programme correctement, il faut s’assurer de 
l’ouverture d’un projet dans Code Blocks, suivez le tuto ou les étapes 
pour mieux comprendre. 
● Il est nécessaire de mettre le terminal en plein écran avant de 
commencer pour le bon fonctionnement des modules d’affichage. 
● Il est nécessaire de respecter les noms et formats des fichiers qui 
contiennent les données, sinon les populations ne peuvent pas être 
créées à partir de fichiers. 
● Utilisez votre clavier (flèches multidirectionnelles) ou votre souris pour 
choisir du menu. 
1. Étapes pour exécuter le programme correctement: 
● Ouvrir Code::Blocks. 
● Créer un nouveau projet : 
● Allez dans Fichier → Nouveau → Projet... 
● Sélectionnez "Projet vide" (Empty Project) → Cliquez sur "Aller", puis Suivant 
● Donnez un nom à votre projet et choisissez le dossier où vous souhaitez 
enregistrer les fichiers du projet. 
● Terminez l'assistant, ne vous occupez pas encore des fichiers sources. 
● Ajoutez vos fichiers .c et .h existants : 
● Dans l’onglet "Projet" à gauche, faites un clic droit sur "Sources" → Ajoutez 
des fichiers... 
● Naviguez jusqu'au dossier où se trouvent vos fichiers .c. 
● Sélectionnez tous les fichiers .c (maintenez Ctrl pour en sélectionner 
plusieurs) → Cliquez sur Ouvrir 
● Faites la même chose pour les fichiers .h, mais faites un clic droit sur 
"En-têtes" (Headers) → Ajouter des fichiers... 
● Compiler et exécuter le projet : 
● Cliquez sur l’icône en forme d’engrenage (Compiler) ou appuyez sur F9 pour 
compiler et exécuter. 
2. Format utilisé dans la partie 1 (pour l’importation de la population à partir d’un 
fichier appelé TP1.txt): 
⇒  Famille1 / famile 2 / ….. / famille n  
● Utilisation du slash (/) comme séparateur. 
● Les noms ne doivent pas nécessairement être formatés Xxxxx. 
● Les espaces ne sont pas nécessaires       
Exemple : bouhadada / khadir/ …/ terki 
3. Format utilisé dans la partie 2 (pour l’importation de la population à partir d'un 
fichier appelé data.txt ): 
⇒ Famille1: prenom parent1;sexe, prenom parent2; sexe: prenom 
enfant1;sexe, …, nom enfantN;sexe: marque voiture1; matricule, …, marque voitureN; 
matricule 
● Chaque famille occupe une ligne. 
● Utilisation de ‘:’ comme séparateur entre les champs d’une famille ( nom: parents: 
enfants: voitures). 
● Utilisation de ‘,’ comme séparateur entre les éléments d’une liste (parent1, 
parent2…). 
● Utilisation de ‘;’ comme séparateur entre les champs de chaque élément (nom 
enfant; sexe …). 
● Utilisation de ‘/’ pour indiquer un champ vide. 
● Les noms ne doivent pas nécessairement être formatés Xxxxx. 
● Les espaces ne sont pas nécessaires. 
Exemple:  
Bensebaa: Djamel;m,khadidja;f: mohammed;m,laatra;f,fouad;m:peugot;12563-111-16 
Sellami: mokhtar;m : / : chevrelet;30924-115-31
